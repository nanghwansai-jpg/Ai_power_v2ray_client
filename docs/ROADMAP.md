# Delivery Roadmap

1. Foundation: Gradle project, module boundaries, CI, and documentation.
2. VPN engine: Android VPNService lifecycle and Xray adapter integration.
3. Configuration: VLESS, VMess, Trojan, Shadowsocks, QR, clipboard, JSON, and subscriptions.
4. DNS and routing: secure DNS, per-app routing, IPv4/IPv6 leak protection, and kill switch.
5. Intelligence: deterministic policy engine, optional on-device AI, and protected Gemini gateway.
6. UI: Material 3 dashboard, node management, diagnostics, and Burmese/English localization.
7. Backend: Cloudflare Workers, D1, KV, R2, and Queues where needed.
8. Security and quality: automated tests, dependency verification, signed updates, and rollback.
9. Release: reproducible signed APK/AAB builds and release readiness review.

A roadmap item is complete only after implementation and relevant tests are verified.
